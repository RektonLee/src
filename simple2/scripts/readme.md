## 2. 数据预处理与图构建

### 2.1 结构预处理（docking.py）

- **功能**：自动化处理蛋白-配体结构，包括去除杂原子、生成配体3D结构、分子对接、口袋提取等。
- **流程**：
  1. 读取蛋白PDB和底物SMILES。
  2. 清理PDB文件（去除金属离子等）。
  3. 用RDKit将SMILES转为3D配体结构。

- **节点特征**：
  - 元素类型one-hot
  - 残基类型one-hot
  - 是否配体原子
  - 最近邻距离
  - 电子结构特征
  - 原子物理化学属性（质量、电负性、半径）
- **边特征**：
  - 原子间距离用高斯RBF扩展为多维特征
- **全局特征**：
  - 温度（标准化后作为全局标量）
- **标签**：
  - kcat、Km（取log10后作为回归目标）
- **输出**：保存为.pt文件的Data对象列表（即PyG数据集）。

随着蛋白质结构预测（如AlphaFold）和机器学习技术的发展，基于结构信息的机器学习催化性能预测逐渐成为研究热点。  
本项目基于Pocket-GNN思路，构建了一个自动化的口袋提取、图构建与GNN预测框架，旨在从蛋白质活性口袋局部结构中直接预测酶的催化动力学参数，并结合解释性分析识别关键活性位点。

# 4. 系统设计与实现

## 4.1 数据集与预处理

本项目使用自建数据集，包含：

- UniProt ID；
- 蛋白质全序列；
- 底物SMILES式；
- 实验测定的\(k_{cat}\)和\(K_m\)数值。

针对每个样本：

1. 从PDB下载对应蛋白质三维结构；
2. RDKit生成底物三维结构，UFF力场优化；
3. 使用PyMOL为底物分子添加氢原子；
4. 标准化处理蛋白质结构，去除水分子、金属离子和杂质原子；
5. 转化蛋白质与底物为PDBQT格式，供后续对接使用。

## 4.2 结合口袋提取与分子对接

- 使用AutoSite自动识别蛋白质表面的潜在结合口袋。
- 以AutoSite生成的最高得分口袋为中心，设定Vina对接网格。
- 使用AutoDock Vina对底物分子进行分子对接，获取结合自由能最低的构象。
- 将对接后底物与蛋白质合并，提取底物5 Å半径范围内所有蛋白质原子，定义为结合口袋Pocket。

## 4.3 Pocket图构建

每个提取到的Pocket结构被转化为图结构：

- 节点：Pocket中的每个原子。
- 边：任意两原子间距离小于4.5 Å建立无向边。
- 特征：节点特征为原子类型（离散编码）。

所有Pocket图数据以PyG `Data`对象存储，并打包为`.pt`文件，供GNN模型读取使用。

## 4.4 GNN模型设计（PocketGNN）

本项目设计了轻量级图神经网络PocketGNN，架构如下：

- **输入**：Pocket图（原子节点+4.5 Å邻域边）
- **嵌入层**：原子类型嵌入至128维稠密向量
- **图卷积层**：连续3层GCNConv + ReLU激活
- **全局池化**：Global Mean Pooling获得图级表示
- **回归头**：多层感知器（MLP）预测\(k_{cat}\)和\(K_m\)

损失函数为均方误差（MSELoss），优化器为Adam。

## 4.5 训练与评估

- 随机划分80%训练集、20%验证集。
- Early-stopping机制防止过拟合。
- 评估指标包括：
  - 平均绝对误差（MAE）
  - 均方根误差（RMSE）
  - Pearson相关系数（r）
  - 决定系数（\(R^2\)）

同时绘制预测值与真实值散点图，直观展示模型性能。

## 4.6 解释性分析

为赋予模型结构可解释性，本项目应用了Input × Gradient方法：

- 对每个Pocket图节点，计算预测输出对其输入特征的梯度。
- 输入与梯度乘积作为该节点的重要性分数（Saliency Score）。
- 将分数写入Pocket PDB结构的B-factor字段。
- 通过PyMOL绘制原子热力图，高贡献原子呈现红色。

此分析揭示了Pocket中哪些原子、哪些局部区域对催化性能预测起到了关键作用。
